Personal portfolio of **S. M. Mushfiqur Rahman Nayeem (`Mushfique`)** — Software Engineer (SWE) at **Alpha FMC (New York)** working in **Unqork** and **React** on enterprise insurance & financial platforms for **Prosperity Life** and **Farm Family**.

Built with a Swiss editorial 12-column grid, dynamic scroll-driven dark/light theme transitions, interactive 2.5D/3D particle figures with hover image-reveal lenses, a 10-chapter Story mode, bilingual `EN | BN` (English / বাংলা) switching, and a procedural Web Audio ambient soundtrack engine.

---

## Highlights & Interactive Features

- **Entry Gate & Dual Experience Modes:** `009 → 000` preloader gate offering **`01 The site`** (full 11-section editorial portfolio) and **`02 The story`** (10-chapter interactive 3D particle narrative).
- **Interactive Dot Portrait with Hover Reveal:** Frameless transparent PNG cutout (`profile-cutout.png`) rendered as thousands of luminance-weighted particles that react to pointer movement and smoothly reveal the photographic portrait inside a cursor lens.
- **Live Dual Working-Hours Clock:** Real-time **New York (`America/New_York`, ET · 09:00–17:00)** working hours paired with **Dhaka (`Asia/Dhaka`, GMT+6)** local time.
- **Borderless Circular Dot-Matrix Metrics:** Custom SVG dot-matrix numeral renderer (`DotMatrixNumber`) for key career, academic, and recognition stats.
- **Enterprise & Independent Work Showcase (`(03) Selected Work`):**
  - **Prosperity Life Group** *(Alpha FMC · Unqork, React, Pathway FIA calculators, Google Charts, API & PDF)*
  - **Farm Family (CCP)** *(Alpha FMC · Unqork, React, PLDC Auto verification, authorization capture, linked policies)*
  - **RannaBhai** *(MERN Stack cooking & meal planning web app)*
  - **KhaboKi** *(Flutter & SQLite multi-household meal/expense manager)*
  - **29 Card Game (Bengal Dynasty)** *(React + GSAP 6-theme trick-taking engine)*
  - **JonoShokti** *(Python, FastAPI & GitHub Issues civic voting platform)*
- **Interactive Capabilities (`(02)`) & Education Accordion (`(04)`):** 6 interactive capability tabs synced to a 3D wireframe dot canvas (`DotStage`), plus a 3-panel horizontal indigo accordion for BRAC University (`3.65 CGPA · 4x Merit Scholar`), RAJUK Uttara Model College (`IELTS 7.5`), and Scholarshome.
- **After Hours (`(07) Music`) & Gaming Arena (`(08)`):**
  - Dedicated Spotify music rotation (`মায়াবী ঘর`, `Half Glass Carew`, `Manush Pakhir Gaan`, `Shohorer Duita Gaan`) paired with 4 switchable Web Audio ambient arrangements.
  - Dedicated dark **Gaming & Arena** chapter featuring an interactive **Valorant Omen** dot-matrix figure with hover reveal, clickable ability particle pulses, copyable Riot ID **`Sirius Black #Black`**, **EA SPORTS FC 27**, and **29 Card Game**.
- **Developer Telemetry (`</> Code`), `EN | BN` Toggle & AI Portfolio Assistant:** Live 12-column grid overlay, FPS/DOM inspector, full Bangla localization, cursor-lens Motto reveal + `Break it` Easter egg, and built-in Q&A assistant.

## Tech Stack

- **Frontend:** React 19, Vite 6, Vanilla CSS (12-column fluid grid & custom properties)
- **Graphics & Audio:** HTML5 2D/3D Particle Canvas, Custom SVG Dot-Matrix Engine, Web Audio API
- **Typography:** General Sans (Fontshare), Hind Siliguri (বাংলা), JetBrains Mono
- **Deployment:** Vercel (`vercel.json` SPA rewrites)
